# Q1_AA1_final-grade-calculator
A Python program that calculates a student's final weighted grade and adjectival rating with input validation.

## Description
This program collects the student's name, student ID, and scores for all required assessments. It validates the user's inputs, calculates the percentage of each assessment component, applies the required weights, and displays the final weighted average and adjectival rating.

## How to Run
1. Open final_grade_calculator.py.
2. Run the program.
3. Enter the requested information when prompted.
